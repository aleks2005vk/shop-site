# 🛍️ ShopSite - E-Commerce Platform

A modern e-commerce platform built with React, Vite, and Redux for seamless shopping experience.

![Version](https://img.shields.io/badge/Version-1.0.0-blue)
![React](https://img.shields.io/badge/React-19-blue)

## ✨ Features

- 🛒 **Shopping Cart Management** - Add, remove, update quantities
- 💳 **Payment Processing** - Secure checkout integration
- 🔍 **Advanced Search** - Smart filtering and categorization
- 📱 **Responsive Design** - Perfect on all devices
- 🎨 **Modern UI/UX** - Beautiful and intuitive interface
- ⚡ **Fast Performance** - Optimized with Vite
- 🔐 **User Authentication** - Secure login system
- 📦 **Order Management** - Track orders and history

## 🚀 Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **State Management**: Redux Toolkit
- **Routing**: React Router DOM
- **Styling**: CSS Modules + Modern CSS
- **HTTP Client**: Axios
- **Development**: ESLint + Prettier

## 📦 Installation

```bash
cd shopsite/shopsite

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Usage

1. Clone the repository
2. Navigate to `shopsite/shopsite`
3. Run `npm install`
4. Execute `npm run dev`
5. Open browser at `http://localhost:5173`
